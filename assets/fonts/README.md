# Fontes dos cartões

Usadas nas imagens geradas no servidor (`opengraph-image`), que precisam de TTF. A página usa as mesmas famílias em WOFF2, em `public/fonts`. Ambas sob a [SIL Open Font License 1.1](https://openfontlicense.org).

- **Newsreader** (Medium), da Production Type: [Google Fonts](https://fonts.google.com/specimen/Newsreader)
- **Inter** (Regular e SemiBold), de Rasmus Andersson: [Google Fonts](https://fonts.google.com/specimen/Inter)
